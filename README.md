# El Señor Dogs — Static HTML Website

This version is ready for GitHub Pages. It uses plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and folder from this project, keeping the `assets` folder intact.
3. Open the repository's **Settings**.
4. Select **Pages** under **Code and automation**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will provide the public website address after it finishes publishing.

## Pages

- `index.html` — Home
- `menu.html` — Menu
- `our-story.html` — Our Story
- `catering.html` — Catering with Jotform
